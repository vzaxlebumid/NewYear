# Новый год — интерактивный сайт

Статический сайт без сборки и серверной части: праздничное представление с ёлкой, фейерверком и музыкой, три мини-игры и несколько небольших функций.

## Что внутри

- **Стартовый экран** с кнопкой «Начать праздник». Ёлка появляется только после нажатия.
- **Праздничное представление**: рост ёлки, гирлянды, искры, фейерверк, музыка и поздравление. Его можно пропустить и запустить заново.
- **Santa Runner** — бег Санты на санях (Пробел или ↑, на телефоне — касание).
- **Christmas Chess** — шахматы для двоих по полным правилам: шах, мат, пат, рокировка, превращение пешки, взятие на проходе, ничьи (недостаточный материал, правило 50 ходов, троекратное повторение). Есть отмена хода и поворот доски.
- **Catch the Gifts** — аркада на 60 секунд (стрелки, A/D, на телефоне — палец).
- Обратный отсчёт до 1 января 00:00 по времени устройства, генератор поздравлений, снежный шар, рекорды и 14 достижений (сохраняются в `localStorage`).
- Управление музыкой: пауза, громкость, выключение звука. Режим «Лёгкий режим эффектов» и поддержка `prefers-reduced-motion`.

## Запуск

Просто откройте `index.html` двойным щелчком. Сервер, терминал и VS Code не нужны: скрипты подключены обычными тегами `<script>`, все пути относительные, внешних библиотек и сетевых запросов нет, поэтому сайт работает и офлайн.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (например, `new-year`), сделайте его публичным.
2. Нажмите **Add file → Upload files** и перетащите **содержимое** папки `NewYearWebsite` (файл `index.html` должен лежать в корне репозитория, рядом с папками `css` и `js`). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

Так как все пути относительные, сайт работает и в подпапке с названием репозитория.

## Музыка и лицензии

Ничего не скачивается и не подключается. Музыка и звуки синтезируются в браузере через Web Audio API. Мелодии — «Jingle Bells» (Дж. Пирпонт, 1857) и «We Wish You a Merry Christmas» (народная английская песня): обе композиции находятся в общественном достоянии, а звучание создано самим кодом, поэтому прав третьих лиц на запись нет.

## Структура

```
index.html
css/style.css
js/core.js            хранилище, рекорды, достижения, уведомления
js/audio.js           музыка и звуковые эффекты (Web Audio)
js/effects.js         снег, фейерверки, искры, ёлка
js/extras.js          отсчёт, поздравления, снежный шар
js/main.js            экраны, представление, площадка
js/games/chess-engine.js   шахматные правила (проверены тестом perft)
js/games/chess.js          интерфейс шахмат и фигуры
js/games/runner.js         Santa Runner
js/games/gifts.js          Catch the Gifts
```

## Свои настройки

- Дата отсчёта и год в поздравлении вычисляются автоматически (`NY.newYear` в `js/extras.js`).
- Тексты поздравлений — массив `GREET` в `js/extras.js`.
- Цвета — переменные в начале `css/style.css`.
